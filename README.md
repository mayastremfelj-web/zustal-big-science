# ŽustAl – Big Science & Space

Pripravljeno za GitHub Pages; brez namestitve ali build koraka.

## Objava

1. Razširi ZIP na računalniku.
2. V nov GitHub repozitorij naloži VSEBINO te mape: index.html, mapo assets, README.md in datoteko .nojekyll. Ne nalagaj ZIP-a ali dodatne nadrejene mape.
3. Shrani s Commit changes.
4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
5. Po končani objavi se povezava prikaže v Settings → Pages.

Pri nalaganju ohrani mapo assets in vse podmape. Video je v assets/zustal-presentation.mp4. Datoteke uporablja index.html prek relativnih poti, zato stran deluje tudi v podmapi repozitorija.

## Urejanje

Besedilo in slog sta v index.html. Slike, originalni grafični elementi, logotipi, pisave in video so v assets. Datoteke export-* so izločeni vgrajeni elementi trenutne različice; ne briši jih ali preimenuj brez popravka povezav v HTML.

Izvoz vsebuje zadnjo različico z robno postavljeno hero fotografijo, poravnanim kontaktnim delom, CERN brez napisa supplier in zelenim ASG. Vključene so tudi izvorne fotografije za nadaljnje urejanje.
